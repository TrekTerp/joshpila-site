Wondrous Worlds: finished website update

Repository: https://github.com/TrekTerp/joshpila-site

GitHub Desktop / local repository
1. Select joshpila-site, switch to main, and pull the latest changes.
2. Extract this ZIP outside the repository.
3. Copy the extracted dnd folder into the repository root, merging folders and replacing the matching dnd/index.html. Keep all other existing files.
4. Review the three changed files, commit with "Add Wondrous Worlds to D&D tools page", and Push origin.
5. Check the repository Actions tab for the deployment result.

GitHub website alternative
1. Open the repository root on main.
2. Choose Add file > Upload files.
3. Drag the extracted dnd folder into the upload area. Upload the folder, not the ZIP. Verify the paths below before committing.
4. Commit the changes to main, then check Actions for deployment.

Only these three website files are included:
- dnd/index.html (updated tools page)
- dnd/wondrous-worlds/index.html (finished themed tool)
- dnd/img/wondrous-worlds.webp (banner)

The DM tool order is Spectacular Settlements, Dangerous Destinations, Wondrous Worlds, Trove.
